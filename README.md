# Quick Start

Dieses Projekt wurde von Overleaf in eine lokale Umgebung (VS Code + GitHub) migriert. 
Hier finden sich die Anweisungen, um das Dokument lokal zu kompilieren.

## 🛠 Voraussetzungen (Dependencies)

Um dieses Projekt erfolgreich zu bauen, müssen folgende Programme installiert sein:

1. **LaTeX Distribution:**
   - **macOS:** [MacTeX](https://www.tug.org/mactex/) (Vollversion empfohlen)
   - **Windows:** [MiKTeX](https://miktex.org/) oder [TeX Live](https://www.tug.org/texlive/)
   - **Linux:** `texlive-full`

2. **Editor:**
   - [Visual Studio Code](https://code.visualstudio.com/)
   - **VS Code Extension:** [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop)

## 🚀 Installation & Setup
